Standalone Xbox/XInput controller support for the compatible Windows Borderlands Online client.

Download **XboxControllerMod-1.0.zip** below, extract it, and follow **TUTORIAL.txt**. No source compilation or Creative mod is required.

Includes gameplay controls, a menu cursor with inventory dragging and scrolling, an on-screen keyboard, button rebinding, adjustable sensitivity/deadzones, and local shot vibration. The installer preserves existing mod hooks and creates backups; an uninstaller is included.

This is an initial preview. Automated input, menu-routing, installation and preservation checks pass; physical Xbox-controller gameplay and individual menus still need an in-game check. Movement retains the game's eight directions. Existing keyboard labels remain, with controller hints supplied by the mod.

Game binaries, assets, saves and other mods are not included.
